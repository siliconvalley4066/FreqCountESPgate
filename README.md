# FreqCountESPgate
Stable and accurate Frequency Counter Library for ESP32

This counts the input pulse by PCNT with the gate signal generated by LEDC.
The gate timing is completely managed by the hardware.
So, it is fairly stable and accurate.

Specifications:
<li>Nominal gate time is 1 second or 0.1 second.</li>
<li>Actual gate time is 937.5ms or 93.75ms.</li>
<li>Frequency range is 1Hz to 40MHz. Practical upper limit is 32MHz.</li>
<li>Input voltage range 0 to 3.3V</li>
<br>
<p>
Develop environment is:<br>
<li>Arduino IDE 2.3.10<br>
<li>esp32 by Espressif Systems version 3.3.11<br>
<br>
Select the board: "DOIT ESP32 DEVKIT V1" or "NodeMCU-32S"<br>
</p>
